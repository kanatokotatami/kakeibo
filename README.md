# 家計簿アプリ（Olive / Gmail 連携）

スマホのブラウザで動く家計簿アプリ（PWA）です。サーバー不要の静的ファイルだけでできています。

## 機能
- **Olive 自動取り込み**：Gmail の Olive（三井住友カード／三井住友銀行）ご利用通知メールを月ごとに読み込み、1日ごとの明細にまとめます（重複登録なし）
- **支出の手入力**：金額・使用用途・決済方法（現金／クレカ／その他）・メモ
- **収入の手入力**：給与・賞与・副業など
- **グラフ**：用途別の円グラフ、日別支出の棒グラフ（決済方法別）、直近6か月の収入・支出の棒グラフ
- **データ保存**：端末内に自動保存。JSON でバックアップ／復元、月ごとの CSV 書き出し

## ファイル
| ファイル | 内容 |
|---|---|
| index.html | 画面 |
| app.js | 処理（保存・グラフ・Gmail 連携） |
| manifest.json / sw.js / icon.svg | ホーム画面追加・オフライン起動用 |

## 1. 公開する（HTTPS が必要）
Gmail 連携には HTTPS の URL が必要です。例：GitHub Pages
1. GitHub で新しいリポジトリを作り、この5ファイルをアップロード
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

（Netlify Drop にフォルダごとドラッグする方法でも公開できます）

## 2. Google OAuth クライアントID を作る（初回のみ）
1. https://console.cloud.google.com/ でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」→ **Gmail API** を有効化
3. 「OAuth 同意画面」→ 外部 → アプリ名などを入力 → スコープに `gmail.readonly` を追加 → **テストユーザーに自分の Gmail アドレスを追加**
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類 **ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：`https://<ユーザー名>.github.io`（パスは含めない）
5. 発行されたクライアントID（`xxxx.apps.googleusercontent.com`）をアプリの **設定** タブに貼り付けて保存

## 3. スマホで使う
- iPhone：Safari で開き「共有」→「ホーム画面に追加」
- Android：Chrome のメニュー →「ホーム画面に追加」

**入力** タブの「この月の Olive 決済を同期」を押すと、表示中の月のメールが取り込まれます。設定で「起動時に今月分を自動同期」をオンにすると、開くたびに今月分を同期します（Google のログイン状態によっては1回タップが必要です）。

## 取り込みの仕組み・調整
- 検索条件（初期値）：`from:(statement@vpass.ne.jp OR smbc.co.jp) ご利用日時`
  - 対象月の期間が自動で追加されます。届いているメールの差出人に合わせて設定タブで変更できます
- 本文の「ご利用日時：2026/11/23 15:42」と次の行の「店名（買物）　638円」を読み取ります
- 「（取消）-970円」の取消メールは、同じ店・同じ金額の直前の決済と相殺します
- 店名から使用用途を自動で振り分けます（コンビニ・スーパー→食費、マクドナルド・すき家→外食 など）。該当しない店は設定の「取り込み時の使用用途」になります
- 「Olive／クレジット」は「クレカ」、デビット・ポイント払いは「その他」に分類
- うまく取り込めなかった月は「この月の取り込みをやり直す」で再取り込みできます
- 取り込んだ明細は一覧タブでタップすると用途や金額を修正できます。削除した明細は再同期しても復活しません
- メールは端末内でのみ解析され、外部サーバーには送信されません（Gmail は読み取り専用権限）

## 注意
- データはブラウザ（端末）ごとに保存されます。ブラウザのデータ削除で消えるため、定期的に **設定 → バックアップを書き出し** をしてください
- 別の端末に移す場合はバックアップ JSON を「バックアップから復元」で読み込みます
